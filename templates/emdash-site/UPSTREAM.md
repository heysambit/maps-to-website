# Upstream source and licenses

This folder began from the official Cloudflare EmDash starter generated by `create-emdash@1.4.0`, using `--template cloudflare:starter`. The matching upstream source is EmDash release `emdash@1.4.0`, commit `10beb8c5a99e41c3a8554b09ac5123c4dddc8d11`, at [`templates/starter-cloudflare`](https://github.com/emdash-cms/emdash/tree/10beb8c5a99e41c3a8554b09ac5123c4dddc8d11/templates/starter-cloudflare). The upstream Cloudflare MIT notice is preserved in [`LICENSE`](./LICENSE).

The source package versions used by this workspace are exact in `package.json`; `pnpm-lock.yaml` pins their transitive graph. Local changes replace upstream sample content, add a per-site seed marker and Access gate, and render through `@studio/landing`. The generated `.env` and editor/provider setup files are intentionally not included.

The supported EmDash 1.4.0 seed contract is `validateSeed(seed)` followed by `applySeed(db, seed, { includeContent, onConflict, storage, skipMediaDownload })`, imported from `emdash/seed`. The schema file contains no entries. The release adapter uses `onConflict: "skip"`, which preserves an existing entry; it does not run as an implicit deployment migration. See [EmDash seed files](https://docs.emdashcms.com/themes/seed-files/) for the exact API and conflict semantics.
